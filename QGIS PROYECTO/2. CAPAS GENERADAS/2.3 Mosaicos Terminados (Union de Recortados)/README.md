# 2.3 Mosaicos Terminados

Ráster multibanda unificado que integra las 5 bandas espectrales (B02, B03, B04, B08, B12) en un solo archivo, listo para el cálculo de índices.

🔗 **[Descargar Mosaicos Terminados](https://drive.google.com/drive/folders/1ClpfeRlQ6uvmMG2n4YdJT7yeOm5bo--b?usp=sharing)**

**Contenido:**

- Ráster multibanda de t1 (5 bandas)
- Ráster multibanda de t2 (5 bandas)
- Sin valores nulos (NoData configurado correctamente)

**Orden de bandas:**

- `@1`: B02 (Azul)
- `@2`: B03 (Verde)
- `@3`: B04 (Rojo)
- `@4`: B08 (NIR)
- `@5`: B12 (SWIR-2)

**Procesamiento:** Apilado con herramienta Combinar y limpieza de NoData con Traducir.
